轻健身 · 多文件最终完整版

目录结构：
├─ index.html
├─ media-config.js
├─ gif-links.js
├─ IMG/
└─ VIDEO/

使用：
- 双击 index.html 可直接打开。
- 部署时把整个目录原样上传，不要只传 index.html。
- VIDEO 已包含开始、暂停、普通结束、Tabata训练/休息、倒数和整场结束音效。
- IMG 目录结构已恢复；把你原项目已有的 IMG 文件夹覆盖回来即可恢复原动作 GIF。
- 即使外部音频加载失败，也会自动使用浏览器合成音兜底。

个人资料：
- 顶部只显示当前性别、身高、体重和腰围，不再重复显示“个人初始基准”。
- 点击“编辑个人资料”可修改性别、身高、初始体重和初始腰围。
- 身高仅用于 BMI；初始体重和腰围仅用于趋势对比。
- 男女性别会改变腰围参考值和30分钟内的默认训练重点。
- 动作次数、等级、升降级仍以实际次数、RIR和训练体感为准，不会仅凭性别判断强弱。

重要：浏览器首次播放声音需要先点击一次页面按钮，这是浏览器的自动播放限制。
